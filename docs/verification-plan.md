# Verification plan and executed status

## Strategy

`packet_builder.py` constructs field bytes. `reference_model.py` independently
parses a complete byte array declaratively; it does not copy the RTL FSM.
Independently specified raw vectors first verify the model's byte order and
late-truncation semantics. Cocotb then compares every payload beat and
descriptor field against that model.

The current executed counts come from machine-readable artifacts generated by
the regression and are reported in the [regression summary](../results/regression_summary.md).
The [verification matrix](../results/verification_matrix.md) is generated from
the named scenarios reported by `directed_rtl_matrix`,
`backpressure_and_sequencing`, and `reset_abort_matrix`; a missing or non-passing
scenario prevents evidence generation.

## Assertion and monitor mapping

| Spec property | Executed mechanism |
|---:|---|
| 1 | RTL immediate assertion plus cocotb prior-stall bundle comparison |
| 2 | Cocotb internal byte-index change monitor gated by prior input handshake |
| 3 | RTL immediate assertion plus cocotb held-descriptor comparison |
| 4 | RTL immediate assertion and cocotb equivalence check |
| 5 | Model scoreboard requires empty output for every early reject |
| 6 | Exact accepted payload byte/length/order scoreboard |
| 7 | Late truncation scoreboard checks final `last=1,error=1` |
| 8 | Good output scoreboard checks final `last=1,error=0` |
| 9 | Same RTL/cocotb stalled-output stability monitor as property 1 |
| 10 | One frame-close driven per transaction and exactly one matched descriptor |
| 11 | Reset-abort tests require cleared result and post-reset sequence zero |
| 12 | Mid-frame external configuration inversion still matches sampled config |
| 13 | RTL/cocotb assertion forbids result valid while payload valid remains |

Icarus warnings that `$error` is not synthesizable refer only to the simulation
assertion module; synthesis defines `SYNTHESIS` and excludes it. Verilator lint
checks the synthesizable files separately and reports zero warnings.

## Randomization and coverage

Seeds 1, 7, 42, and 2027 each generate 200 frames. The generator mixes every
reason, payload-size bins, filters, padding, DF, five truncation regions, input
gaps, output stalls, result stalls, and output semantics. Every transaction is
fully deterministic for its seed. Functional coverage reports raw hit counts,
not a percentage.

## Evidence chain

`scripts/run_all.py` removes previous generated results before starting and
writes a run manifest containing source identity, timing, and per-step status.
`scripts/run_regression.py` saves JUnit XML, the pytest/cocotb log, and raw
simulation JSON. `scripts/run_lint.py` and `scripts/run_synth.py` save command,
version, gate status, warnings, and synthesis statistics.
`scripts/generate_results.py` validates those artifacts before creating the
human- and machine-readable summaries. A failure leaves a failure manifest and
current-run logs without retaining prior pass summaries.
